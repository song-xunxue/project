### 核对了什么
逐行对照 `code/calib/{data_utils,calibration,lm,experiment}.py` 与作者 `run_classification.py`/`utils.py`（本地副本）+ 作者 `data_utils.py`/`README.md`（**本次从 master 新下载**，本地参考副本缺这两份）：

### 发现的问题（均未影响任何数字）
- **minor｜未声明的实质差异（3 处，逐一验证不影响结果）**：
  1. 未实现作者 `params_check`（标签词单 token 断言）。本评审已用 tokenizer 验证 13 个标签词全部单 token，实证无害；建议在 README §6 补一句声明。
  2. `first_token_topk` 用 `log(probs+1e-30)` 而作者 `log(probs)`：仅影响 top-k 内下溢到 0 的概率（偏差 ~1e-31 量级），可忽略。
  3. `get_label_probs` 缺失表按"标签词"粒度记录（作者按"类"粒度），AGNews 类3 双词全缺时 (i,3) 入表两次→同一批回声 prompt 算两遍、覆盖写回同值——结果逐位等价（已由维度1的 300 条复算证实），仅多花计算。
  4. attention_mask 取自 tokenizer padding 而作者用 `(ids != 50256)` 推断——本地更稳健（真实文本含 EOS 时作者方案会误判），语义等价。
- **minor｜参考副本可核验性**：`参考说明.md` 文件清单列出 `data_utils.py` 与 `README.md`，但 `作者代码/few-shot-learning/` 下实际不存在（当时 zread 在线读取未落盘）。本次已用新下载件证实"prompt 参数逐字一致"的主张为真，但**该主张目前无法从包内证据独立复核**。建议把这两份文件补落盘进参考副本（连同获取日期与来源 URL）。
- **minor｜`参考说明.md` 环境版本写错**："本组使用现代版本（torch 2.9 / transformers 4.x）"——实测 repro 环境 torch 2.14.1+cu126 / transformers 5.22.1 / numpy 2.4.6 / pandas 3.1.0；`code/README.md` §3.1 的"transformers 5.x"才是对的。
- 备注：`expr_name` 格式与作者（`..._300_subsample_seed0` vs 本地 `..._sub300_seed0`）不同，属工程命名不涉科学内容。
